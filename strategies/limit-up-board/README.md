# 2进3 打板龙头策略

> 基于 A 股 3 年（2023-2026）5480 次连板事件统计验证

---

## 策略概述

专注于寻找**连续 2 日涨停、次日有望封 3 板**的强势龙头股。  
通过**换手率 + 量比**两个核心指标过滤浮筹风险，在胜率最高的时机参与打板。

---

## 核心数据依据

| 指标 | 成功封3（1965次）| 失败止于2板（3515次）| 差异 |
|------|--------------|-----------------|------|
| 2板换手率中位 | **5.5%** | **9.5%** | 高换手=浮筹多=难封 |
| 2板量比中位 | **1.2** | **1.8** | 放量=主力在出货 |
| 首板股价中位 | ¥10.4 | ¥11.8 | 低价股更容易连板 |

| 首板市值 | 2进3成功率 |
|---------|-----------|
| 20~50亿 | **39%**（最优）|
| 50~100亿 | 35% |
| 100~300亿 | 31% |
| >300亿 | 23% |

**板位换手规律（5板以上 465 只样本）：**

| 板位 | 换手中位 | 量比中位 | 含义 |
|------|---------|---------|------|
| 第1板 | 5.5% | 1.4 | 放量启动 |
| 第2板 | 4.4% | 1.1 | 缩量锁仓（关键）|
| 第3板 | 3.9% | 0.9 | 继续缩量 |
| 第4板 | 4.6% | 0.9 | 微放量 |
| **第5板** | **10.8%** | **1.4** | 放量分歧，高风险信号 |

## 选股条件（收盘后扫描）

### 必须满足（硬性条件）

```
✅ 已连续 2 日涨停（打 3 板）
✅ 今日换手率 < 7%        （3年成功中位 5.5%）
✅ 今日量比   < 1.5        （3年成功中位 1.2）
✅ 流通市值   20~150 亿    （最优 20~50 亿）
✅ 股价       ¥4~¥40
✅ 非 ST、非退市风险股
```

### 加分项（排序参考）

```
⭐ 市值 20~50 亿（成功率最高区间）
⭐ 换手 < 5.5%（低于历史成功中位）
⭐ 量比 < 1.2 （低于历史成功中位，缩量封板）
⭐ 有明确催化题材（政策/事件/行业联动）
⭐ 同板块多只同步上涨（板块效应）
⭐ 3板以上高度板（已验证强度）
```

### 直接排除

```
❌ 换手率 > 12%（浮筹过多）
❌ 量比 > 3（明显放量，主力出货嫌疑）
❌ 市值 > 200 亿（资金需求过大）
❌ 股价 > ¥40 或 < ¥4
❌ ST 股、*ST 股
❌ 全市场涨停比 < 0.8%（熊市信号，暂停打板）
```

## 入场操作（次日）

### 集合竞价阶段（9:15~9:25）

| 开盘位置 | 操作 |
|---------|------|
| 高开 3%~8% | ✅ 最优，挂涨停价参与 |
| 高开 < 3% | ⚠️ 市场热情不足，谨慎 |
| 高开 > 10% | ❌ 开板风险极大，放弃 |
| 低开 | ❌ 直接放弃 |

**竞价封板判断（9:20~9:25）：**
- 涨停挂单 > 流通股 1% → 封板意愿强，可参与
- 竞价已锁定涨停 → 最强信号，优先参与

### 开盘后处理

```
情况一：开盘直接封板
  → 持有，不动

情况二：开盘未封，在 -5% 以内震荡
  → 等待，若 3 分钟内回封则持有
  → 超过 3 分钟未封 → 止损

情况三：开盘直接跌超 -5%
  → 立即止损，不再等待
```

## 持仓管理

### 仓位控制

```
单票仓位：总资金 20~25%
同时持有：最多 4 只
不追加仓位（打板价即成本）
```

### 止损规则（严格执行）

| 触发条件 | 动作 |
|---------|------|
| 开板后跌 > 5% 且 3 分钟内未回封 | 立即止损 |
| 全天未封板，收盘前 15 分钟 | 清仓止损 |
| 次日低开超 -8% | 开盘第一时间清仓 |
| 持仓 5 日无新高 | 止损出局 |

### 止盈规则

```
第 3 板（打板当天）：持有不动

第 4 板收盘：
  换手 < 8%  → 继续持有
  换手 > 12% → 减仓 50%

第 5 板出现：
  换手 > 10% 或量比 > 2 → 清仓 80%，留 20% 博更高
  高开超 8% 当天无法再封板 → 开板立即全清

第 5 板以后（高度板）：
  连续 2 天换手 > 10% → 全部清仓
  出现大阴线 / 长上影线 → 次日开盘清仓
```

## 大盘状态过滤

| 5日均涨停比 | 市场状态 | 打板策略 |
|-----------|---------|---------|
| ≥ 2.0% | 牛市 | 积极参与，仓位可满 |
| 0.8%~2.0% | 震荡市 | 严格执行换手/量比过滤，半仓 |
| < 0.8% | 熊市 | **暂停打板，空仓等待** |

- **C级**：关键指标超标（主要是量比过大），风险高，建议回避

---

## 风险提示

1. **高开炸板**：3板高开 > 8% 极易开板出货，是最常见亏损来源
2. **第5板换手放量**：换手突破 10% 是主力出货信号，立即减仓
3. **熊市打板**：全市场赚钱效应差时，即使选股正确也容易被大盘拖累
4. **连板数越高风险越大**：高度板追涨需更严格的止损
