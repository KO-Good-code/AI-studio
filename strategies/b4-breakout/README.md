## 策略核心思路

**"找到横盘整理 2~3 个月的股票，等它放量突破再买入"**

股价长时间横盘说明买卖双方力量平衡，多空都在等待。当某天成交量突然放大并同时创出区间新高，往往意味着有资金选择此时进场，是趋势启动的信号。策略不预测方向，只跟随放量突破的事实买入，用止损控制风险。

**双策略轮动的必要性：**

| 市场阶段 | 突破信号质量 | 最优操作 |
|---------|------------|---------|
| 牛市 | 高，多数突破有效 | 突破当天直接买入（原版），不等回踩，快速建仓 |
| 震荡市 | 低，假突破多 | 等回踩确认（RT10），旧阻力变新支撑再买入 |
| 熊市 | 极低，几乎都是假突破 | 全部空仓，等待转机 |

## 双策略保守版（推荐）

### 概述

根据 A 股**涨停比**（每日涨停股数 / 总股数，取 5 日均值）判断市场阶段，自动切换入场策略：

```
涨停比 ≥ 2%   → 牛市  → B4 原版（突破当天买），最多 5 仓
0.8% ~ 2%    → 震荡  → B4-RT10（回踩确认），最多 3 仓
< 0.8%       → 熊市  → 空仓，不开新仓
```

### 为什么用涨停比判断大盘？

涨停比是 A 股独有的极佳情绪指标：
- **涨停股数反映市场赚钱效应**：≥100 只涨停时资金积极参与，市场处于上行趋势
- **5 日均值平滑毛刺**：避免单日数据噪声干扰判断
- **领先性强**：市场情绪往往领先于指数价格（涨停比下降是预警信号）

### 双策略切换逻辑

```
每个交易日收盘时：
  计算今日涨停股数占比 → 更新 5 日滚动均值

  if 5日涨停比 ≥ 2%:
    今日为"牛市"环境
    买入规则 = B4 原版（high_break_60 突破当天）
    最大持仓 = 5 只

  elif 5日涨停比 ≥ 0.8%:
    今日为"震荡市"环境
    买入规则 = B4-RT10（近10天突破 + 今日回踩反弹）
    最大持仓 = 3 只

  else:
    今日为"熊市"环境
    不开新仓，持仓到止损触发自然退出
```

## B4 原版（单一突破）

### 建仓条件（7 条必须同时满足）

| # | 指标 | 条件 | 目的 |
|---|------|------|------|
| 1 | 创 60 日新高 | 当日收盘价 > 近 60 个交易日最高收盘价 | 确认突破平台压力位 |
| 2 | 量比 ≥ 2x | 当日成交量 ≥ 近 20 日均量的 2 倍 | 确认放量，排除缩量假突破 |
| 3 | ATR ≤ 5% | 近 40 日平均真实波幅 ≤ 5% | 确认之前是低波动横盘，非大幅震荡 |
| 4 | 当日涨幅 ≥ 1% | 当日收盘涨幅 ≥ 1% | 收涨，有上行动能 |
| 5 | 非涨停 | 未触发涨停板 | 次日可正常买入 |
| 6 | 开盘涨幅 ≤ 5% | 开盘涨幅（相对昨收） ≤ 5% | 避免追高开盘 |
| 7 | 非 ST | 非 ST / *ST 状态 | 排除退市风险 |

### 买入执行

- **信号日**：收盘后确认满足全部条件
- **买入时机**：次日开盘价附近买入
- **仓位**：最多同时持有 5 只，每只约占总资金 20%
- **优先顺序**：同日多只信号时，**量比最高**者优先

## B4-RT10（回踩确认版）

### 核心思路

> 突破后不急着买，等价格回踩突破位，确认「旧阻力变新支撑」再入场

```
时间线示例：
  Day 0：突破 60 日高点，放量上涨（记录突破事件）
  Day 1~10：价格回落至突破位附近（缩量整理）
  今日：价格创 5 日新高，再次放量向上 ← 买入信号
```

### 建仓条件（7 条必须同时满足）

| # | 指标 | 条件 | 说明 |
|---|------|------|------|
| 1 | 近期有突破 | 近 10 个交易日内曾出现 60 日新高 | 确认突破事件存在 |
| 2 | 回踩幅度 | 今日价格偏离 60 日高点：-5% ~ +2% | 价格在突破位附近（未跌太深）|
| 3 | 反弹确认 | 今日创 5 日新高 | 从回踩低点向上启动 |
| 4 | 量能跟上 | 量比 ≥ 1.5x | 反弹有量，非死猫跳 |
| 5 | 趋势完整 | 价格在 MA20 上方 | 均线结构未破坏 |
| 6 | ATR ≤ 5% | 近 40 日 ATR ≤ 5% | 平台结构确认 |
| 7 | 通用过滤 | 非涨停 + 开盘幅度 ≤ 5% + 非 ST | 同原版 |

### 优势与代价

| 项目 | B4 原版 | B4-RT10 |
|------|---------|---------|
| 入场时机 | 突破当天 | 突破后 1~10 天 |
| 假突破过滤 | 弱（靠量比） | 强（确认旧阻力→新支撑）|
| 牛市收益 | 高（抓第一波）| 略低（可能踏空强势股）|
| 熊市亏损 | 高 | 低（大多数假突破已回落）|
| 平均止损幅度 | ~10% | ~8%（入场价更低）|

## 止损规则

两条规则并行执行，**任一触发即次日开盘卖出**：

### 规则一：趋势止损

```
触发条件：收盘价 < MA20 × (1 - 3%)
```

即跌破 20 日均线超过 3%，说明短期趋势已走坏，不继续等待。

### 规则二：追踪止损（锁定利润）

```
触发条件：当前收盘价 < 持仓期最高收盘价 × (1 - 10%)
```

- 买入后若立刻下跌 10%：及时止损（假突破）
- 买入后先大涨再回落：从最高点保护 90% 的涨幅

### 止损纪律

> **止损是策略能盈利的前提，绝不能因主观判断跳过止损。**

策略盈利模型（胜率约 35~40%）：
```
期望值 = 胜率 × 平均盈利 - 败率 × 平均亏损
       = 37% × 18% - 63% × 8%
       = 6.7% - 5.0%
       = +1.7% 每笔（正期望）
```
只有严格执行止损，才能保证"输小赢大"的结构。

## 实操 SOP

```
每个交易日收盘后执行：

① 查看大盘环境
   → 计算今日涨停股数（可用行情软件"涨跌停"栏）
   → 估算5日均值：(今日 + 近4日涨停比) / 5
   → 判断当前阶段：牛市 / 震荡市 / 熊市

② 扫描候选股
   牛市时：运行 strategy-dual-conservative.ts 或按B4原版条件手动筛
   震荡时：运行 strategy-dual-conservative.ts 或按B4-RT10条件筛
   熊市时：跳过，不建仓

③ 按量比排序，取前 (5 - 当前持仓数) 只
   牛市最多5只，震荡市最多3只

④ 次日开盘附近买入
   若次日跳空高开超 3%，放弃本次信号

⑤ 每日收盘检查持仓
   → 收盘价跌破 MA20 超 3%？  → 明日开盘卖出
   → 从最高价回落超 10%？      → 明日开盘卖出
   → 两者均未触发？             → 继续持有
```

## 常见问题

**Q：胜率只有 35%~37%，为什么能盈利？**  
A：策略靠"盈亏比"而非胜率赚钱。平均盈利约 +15~20%，平均亏损约 -8~10%，盈亏比约 2:1，正期望值约每笔 +1.5~2%。关键是严格执行止损。

**Q：震荡市为什么最多只开 3 仓，而不是 5 仓？**  
A：震荡市假突破概率高，即使用 RT10 过滤后仍有较多错误信号。3 仓相当于限制了噪音信号的总暴露量——3年回测中，保守 3 仓比激进 5 仓多赚约 14 个百分点（+28% vs +13.8%）。

**Q：涨停比的数据从哪里查？**  
A：每日收盘后，东方财富「涨跌停」板块实时显示涨停家数；或用代码 `scripts/update-prices.ts` 更新本地数据库后，引擎会自动计算。

**Q：什么情况下临时忽略大盘过滤（强行操作）？**  
A：不建议。大盘过滤是策略保护资金的核心机制，临时忽略相当于手动"关掉安全阀"。如果你对某只个股非常确信，建议只用不超过总资金 10% 的仓位试探，而非按标准规则全仓进入。

**Q：能同时持有涨停比过滤版（原版）和 RT10 版各自找的股票吗？**  
A：双策略保守版已内置这个逻辑——牛市时自动用原版找突破，震荡时自动用 RT10 找回踩，不需要手动分别运行两个版本。
